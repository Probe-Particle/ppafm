## Data Formats (CRITICAL)

### Force Field Format: `[nx, ny, nz, 3]`
- **Shape**: 4D array with components (Fx, Fy, Fz) in last dimension
- **Ordering**: C-contiguous (row-major)
- **Indexing**: `FF[ix, iy, iz, 0] = Fx`, `FF[ix, iy, iz, 1] = Fy`, `FF[ix, iy, iz, 2] = Fz`
- **Memory layout**: Strides follow C-order (x fastest, then y, then z, then component)
- **C++ expects**: `Vec3d *gridF` where `gridF[i3D(ix, iy, iz)]` gives `Vec3d(Fx,Fy,Fz)`

### Energy Field Format: `[nx, ny, nz]`
- **Shape**: 3D scalar array
- **Ordering**: C-contiguous
- **Indexing**: `E[ix, iy, iz]` = energy at grid point
- **C++ expects**: `double *gridE` where `gridE[i3D(ix, iy, iz)]` gives scalar

### Lattice Vector (lvec): `[4, 3]`
- **Structure**:
  - `lvec[0] = [0, 0, 0]` - origin (not always used)
  - `lvec[1] = [ax, ay, az]` - cell vector a (x-direction)
  - `lvec[2] = [bx, by, bz]` - cell vector b (y-direction)
  - `lvec[3] = [cx, cy, cz]` - cell vector c (z-direction)
- **Purpose**: Defines grid cell geometry for coordinate transforms
- **Used by**: [setGridCell()](cci:1://file:///home/prokop/git/ppafm/cpp/ProbeParticle.cpp:357:0-361:1) in C++, [grid2cartesian()](cci:1://file:///home/prokop/git/ppafm/cpp/Grid.h:40:1-44:2) / [cartesian2grid()](cci:1://file:///home/prokop/git/ppafm/cpp/Grid.h:46:1-50:2) conversions

### Coordinate Systems
1. **Grid coordinates** (ix, iy, iz): Integer indices
2. **Fractional coordinates** (gx, gy, gz): Float in [0, nx], [0, ny], [0, nz]
3. **Cartesian coordinates**: Real-space positions via `pos0 + gx*dCell.a + gy*dCell.b + gz*dCell.c`

### File Formats

#### XSF format
- **Vector field**: `fname_x.xsf`, `fname_y.xsf`, `fname_z.xsf`
- **Scalar field**: `fname.xsf`
- **Header**: Includes lattice vectors and dimensions

#### NPY format
- **Vector field**: `fname_x.npy`, `fname_y.npy`, `fname_z.npy`, `fname_vec.npy`
- **Scalar field**: `fname.npy`, `fname_vec.npy`
- **Simpler**: Direct numpy binary, no parsing overhead

## Key Implementation Details

### Coordinate Ordering
- **Kriging**: `[nz, ny, nx]` (z slowest, then y, then x)
- **PPAFM/C++**: `[nx, ny, nz]` (x fastest, then y, then z)
- **Action**: Must transpose: `vol.transpose(2, 1, 0)`

### Memory Contiguity
- **Requirement**: C-contiguous arrays for ctypes interface
- **Check**: `np.ascontiguousarray()` after transpose
- **GridUtils**: Already handles this with `.copy()` in load functions

### Lattice Vectors
- **Kriging grid**: Orthogonal (xs, ys, zs are linspace)
- **PPAFM**: Supports triclinic (general 3x3 cell matrix)
- **Action**: Construct `lvec[4,3]` from grid extent
  ```python
  lvec = np.array([
      [0, 0, 0],
      [xs[-1] - xs[0], 0, 0],
      [0, ys[-1] - ys[0], 0],
      [0, 0, zs[-1] - zs[0]]
  ])
  ```

### Force Sign Convention
- **Kriging**: `F = -∇E` (force = negative gradient of energy)
- **PPAFM**: Expects forces as `F = -∇E`
- **Action**: Ensure sign is correct (already correct in analytical derivative)

## Data Alignment Requirements

### Coordinate Systems
1. **Tip Coordinates**: Defined by `scanMin`, `scanMax`, `scanStep` in PPU.params
2. **Probe Coordinates**: Shifted by `r0Probe` from tip coordinates
   - `rProbe = rTip - r0Probe`
   - Default: `r0Probe = (0, 0, 4)` Å (probe hangs 4 Å below tip apex)
3. **GridFF Coordinates**: Interpolated grid where force field is defined
   - z-range: 1.6-6.0 Å (fixed)
   - dz: 0.1 Å

### Critical Alignment Rules
1. **Tip z must be higher than GridFF z by at least `r0Probe[2]`**
   - If GridFF z = 1.6-6.0 Å and `r0Probe[2] = 4` Å
   - Then tip z must be ≥ 5.6 Å to keep probe in grid
   - Recommended: tip z = 6.6-12.0 Å (6.6 = 1.6 + 4 + 1 Å margin)

2. **GridFF slice indexing must account for probe offset**
   - `z_probe = z_tip - r0Probe[2]`
   - GridFF z-index: `iz_grid = int((z_probe - z_offset - z0) / dz)`
   - Use `z_offset = 5.0` Å to shift coordinate systems

3. **Filter OutFz slices to valid probe z range**
   - Only plot slices where `z_probe >= 5.0` Å (or other threshold)
   - Avoids plotting regions where probe is outside GridFF

### Visualization Alignment
- **GridFF_vs_OutFz.png**: GridFF slices shifted by 5 Å relative to OutFz
- **No modulo wrapping**: Clamp indices to valid range to avoid discontinuities
- **Symmetric colormaps**: Use bwr with `vmin=-vmax` for displacement fields
